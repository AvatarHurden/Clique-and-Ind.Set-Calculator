# screenshots

Put project screenshots in this directory (PNG, JPG, GIF).

Guidelines:
- Use descriptive filenames, e.g. `screenshot-01.png`, `running-example.png`.
- Prefer PNG for UI screenshots.
- Try to keep image file size reasonably small (e.g., under a few MB).

You can add image files directly in this folder; this README is a placeholder so the directory exists in the repo.
